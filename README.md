# Diet Flex Tracker + Olahraga

Versi ini mempertahankan tampilan dari repo `ardianreiss/kalori`, lalu menambahkan fitur olahraga di bagian bawah.

## Fitur
- Profil tubuh
- BMI, BMR, TDEE
- Target kalori dan makro
- Log makanan per tanggal
- Log olahraga per tanggal
- Kalori masuk, kalori keluar, kalori bersih
- Import/export JSON
- Data tersimpan di browser via localStorage

## Cara pakai
Upload semua file ke GitHub Pages:
- index.html
- style.css
- app.js
- README.md
